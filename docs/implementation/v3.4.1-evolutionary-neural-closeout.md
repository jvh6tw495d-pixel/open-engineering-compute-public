## Decision

**GO** to declare the evolutionary neural training requirement **closed at
industrial incubation level**:

- Three modes implemented as skills + kernel.
- Hybrid evo→gradient is the strategic default for non-toy models.
- Native pymoo multi-obj neural search (rmse, n_params) + multi-seed hybrid outer.
- Strategy benchmark (gradient / hybrid / neuroevolution) under shared budget.
- No proprietary product branding in OEC docs (Horizon inference engine excluded).
