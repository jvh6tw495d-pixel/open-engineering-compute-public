## 2. What 2.6.1 contains

### Physics modules (`src/oec/physics/`)

| Module | Role | Key symbols |
|--------|------|-------------|
| `storage` | BESS trajectory; **energy-based SOC** (not coulomb) | `energy_based_soc_update`, `storage_trajectory` |
| `pv` | Generic PV v0 | `pv_power`, `pv_energy_from_series` |
| `hybrid` | Multiperiod power balance | `hybrid_balance`, `hybrid_period_residual` |
| `grid_zero` | **Deterministic** feasibility only (no LP) | feasibility helpers over provided trajectories |
| `service_metrics` | Public EaaS concept metrics | `energy_delivered`, `autonomy_hours` |

Conservation residual ownership remains **`oec.physics.conservation`** (2.6.0 / ADR 0024). Kernel `energy.metrics` is adapter/parity, not a rival owner.

### Skills (new; legacy untouched)

| Skill | Class | Notes |
|-------|-------|-------|
| `battery.soc_trajectory` | physics | Multi-step energy-based SOC path |
| `energy.pv_power` | physics | PV power / energy from model or series |
| `energy.hybrid_balance` | physics | Multiperiod hybrid residual / balance |
| `energy.grid_zero_feasibility` | physics | Feasibility of a **provided** trajectory |
| `energy.min_storage_capacity` | **optimization** | Composes `optimization.lp` (HiGHS); **not** physics sizing |
| `energy.service_metrics` | physics | Energy delivered + autonomy hours |

**Legacy (unchanged in 2.6.1):** `energy.balance`, `energy.load_metrics`, `battery.soc_step`.

### Envelope / MCP

- Skills under `energy.*` / `battery.*` → `kind: "energy_result"` (schema ≥1.1).
- **No** new MCP tools.
- Wrap-once `authoritative_answer` intact (ADR 0023).

### ADR

| ADR | Status |

| 0024–0026 | Accepted (Foundation; not reopened) |
| **0027** Energy-systems physics scope | **Accepted 2026-08-04** |

Closed in 0027: energy-based SOC naming; grid-zero feasibility vs min-capacity split; conservation ownership inherited; no legacy migration; feature-release declaration despite patch number; power-signal conventions.
