## 3. Accepted residual limitations (not blockers)

- Infeasibility skill = **drop-one heuristic**, not certified IIS.
- Morris = **linear-model only**.
- Kalman R must be **positive definite** (semidefinite not supported).
- Spectral stability ≠ classical gain/phase margins.
- Wave C is **v0** (supported Pareto points; CVaR min-only; robust equalities unsupported).
- Math IR / formal Verification / Backend Registry = **v2.4+** (by design).
