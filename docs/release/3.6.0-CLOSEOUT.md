## Explicit limitations

- All skills remain **experimental**. S2/S3 hardening is not a status promotion.
- Remote VLM positive smoke is not asserted when a pinned model/weights are not
  available locally; bounded/fail-closed and discovery tests are the portable gate.
- This closeout creates neither a tag nor a push, merge, publication, or remote CI run.
- Foundation, neural, and evolutionary functionality remains optional; a core install
  must not pull torch, pymoo/DEAP/Nevergrad, Transformers, PEFT, or Pillow.
