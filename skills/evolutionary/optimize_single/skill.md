# Single-Objective Evolutionary Optimize

Box-constrained single-objective search via **pymoo** on built-in test
problems (`sphere`, `rosenbrock`, `rastrigin`). Requires
`uv sync --extra evolutionary`.

No user Python fitness functions (ADR 0031).
