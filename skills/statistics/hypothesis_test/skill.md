# Purpose

Run closed-catalog hypothesis tests via SciPy. OEC governs the contract and
returns statistic + p-value; it does not invent scientific conclusions.

# Official methodology

Method id: `scipy_stats_hypothesis`.

Tests: `t_one_sample`, `t_two_sample`, `ks_1samp`, `mannwhitney`.
