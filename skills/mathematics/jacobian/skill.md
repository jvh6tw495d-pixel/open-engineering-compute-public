# Purpose

Approximate the Jacobian matrix of one or more safe expressions with respect
to named variables via finite differences (W1).

# Official methodology

Method id: `finite_difference_jacobian`.

Expressions use the restricted AST grammar (`oec.kernel.numerics.expressions`).
