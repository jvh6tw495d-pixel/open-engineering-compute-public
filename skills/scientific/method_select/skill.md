# Scientific Method Selection (X3)

Given a declarative `problem_class`, list OEC skills that apply, filter by
backend availability, optionally run a tiny probe benchmark, and return the
recommended `skill_id` + `method_id`.

**Agent must still execute the selected skill** — this skill does not invent
numerical engineering answers.
